## 🛠 Технологический стек

- **Backend:** ASP.NET Core 8 (Modular Monolith), C#
- **Frontend:** React (Vite + TypeScript), Tailwind CSS
- **Database:** PostgreSQL (основные данные), Redis (кэш и сессии)
- **Real-time:** SignalR (текстовые чаты, уведомления)
- **AI & Moderation:** OpenAI API (редактор синонимов, анализ тональности), AI Image Moderation
- **Video/Audio Calls:** LiveKit (PaaS решение для WebRTC)
- **Infrastructure:** Docker, VPS (Hetzner/Cloudflare), GitHub Actions (CI/CD)
